# Audit

Audit reports what [align](align.md) and [polish](polish.md) would change in a project, and leaves the project unchanged.

1. **Set the scope and run the baseline** by align's *Set the scope* and *Read the standards and run the baseline*, on the path, module or project the user names, with its tests, else the whole project. Done when both done conditions hold.
2. **List the findings:**
   - each proposal align's *Settle the standards* would make;
   - each flaw align's *Plan the changes* would list against the project's standards, and against nus-mode where they are silent;
   - each cut and split polish's *Cut, with proof* would list.

   Done when each baseline failure is a finding; each case *Settle the standards* names was checked; each file in scope was read against the project's standards and each principle and language skill that applies; and each finding gives every instance, or the command that lists them, its rule and its fix.
3. **Confirm each finding** as nus-mode's *Treat each review finding as a hypothesis* says, and trace it to its cause. Route it to polish when polish's *Cut, with proof* would make its fix, else to align, and merge the findings that share a cause and a route into one at that cause. Done when each refuted finding is dropped; each kept one rests on observed evidence at its traced cause; and each proposal, and each align finding that changes a name or behaviour align keeps, is marked.

**Reply:** the scope, then each marked finding, then the rest, each as step 2 gives it, with its evidence and route.
